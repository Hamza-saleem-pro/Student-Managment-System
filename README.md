## 🎓 Student Management System (Bash)

A simple terminal-based student management system built in Bash that supports:

- 👨‍🏫 Teacher login for managing students
- 👨‍🎓 Student login to view personal records
- 📚 Add, update, delete student records
- 📝 Record grades and calculate CGPA
- 📊 Generate and sort student reports

### 🚀 How to Run

```bash
chmod +x student_management.sh
./student_management.sh
```
